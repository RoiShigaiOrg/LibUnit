**Description**

    This project is about replicate the function printf from the <stdio> of C language,
        the printf of this project doesn't convert the flags system, just the normal conversion
        for the integer, the strings, the char && pointers value.

**Instruction**

    The project must be compile by using the  'make all'
        -> It will create a static library 'libftprintf.a'
    Other Makefile rules are present : 
        - Make clean : to delete the object files
        - Make fclean : to delete the result static library and all object files
        - Make re : to recompile the library from the begining

    As recommended in the subject the resulting library will contain some functions from the 'libft' library
    To use the library, the user must compile a c file with a main function with the 'libftprintf.a' library
        to create a binary.
